# Morsi Cashier

تطبيق Tauri مستقل للكاشير. هذه بداية التنفيذ وتشمل حساب المدير الأول، تسجيل الدخول، إضافة حسابات البائعين، التصنيفات، المخازن، الموردين، المنتجات ومتغيرات الأحذية، البيع وخصم المخزون، وقائمة الفواتير.

## التشغيل

```bash
cd /home/abdo/Documents/Morsi
npm install
npm run tauri dev
```

لبناء الواجهة فقط: `npm run build`. لبناء نسخة سطح المكتب: `npm run tauri build` بعد تثبيت متطلبات Tauri للنظام.

## بناء نسخة Windows من GitHub Actions

بعد رفع المشروع إلى مستودع GitHub، افتح تبويب **Actions** ثم اختر **Build Windows installers** واضغط **Run workflow**. عند اكتمال التشغيل، افتح نفس التشغيل ونزّل `morsi-windows-exe` أو `morsi-windows-msi` من قسم **Artifacts**. كل ملف تنزيل يكون ZIP بداخله ملف التثبيت.

الـ workflow يستخدم جهاز Windows من GitHub، لذلك يمكن تشغيله حتى لو جهاز التطوير Fedora. ملفات التثبيت الناتجة غير موقعة رقميًا، وقد يُظهر Windows تحذيرًا عند تشغيلها. يوجد ملف الـ workflow في `.github/workflows/build-windows.yml` ويجب رفعه مع بقية ملفات المشروع. إذا لم يكن المشروع على GitHub بعد، أنشئ مستودعًا وارفع الملفات إليه؛ يظهر زر التشغيل بعد وجود الـ workflow على الفرع الافتراضي.

## تشخيص إغلاق نسخة Windows عند الفتح

مثبت Windows من الإصدار 0.1.2 يضمّن مثبت WebView2 دون الحاجة إلى تنزيله وقت التثبيت. إذا استمر إغلاق البرنامج، افتح `%LOCALAPPDATA%\com.morsi.forbelt\startup.log` بعد محاولة تشغيله، وأرسل آخر السطور للتشخيص. قد يظهر `startup-error.log` في المجلد نفسه إذا أعاد Tauri خطأ أثناء بدء التشغيل. إذا لم يتكوّن أي سجل، راجع الخطأ في Event Viewer ← Windows Logs ← Application. لا تحذف مجلد البيانات أو ملف `cashier.sqlite` أثناء التشخيص.

## حفظ البيانات والتحديثات

- قاعدة SQLite في مجلد بيانات التطبيق المحلي الخاص بمعرّف `com.morsi.forbelt`، خارج ملفات التثبيت.
- ترحيلات قاعدة البيانات في `src-tauri/migrations`، وتعمل عند فتح التطبيق. كل تغيير جديد في البنية يضاف بملف ترحيل جديد؛ لا تُعدل ملفات الترحيل المنشورة بعد تسليم نسخة للعميل.
- هذه النسخة مخصصة لجهاز واحد. تشغيل أكثر من جهاز يحتاج خدمة وقاعدة بيانات مركزية قبل الاستخدام الفعلي المتزامن.
- يتضمن التطبيق منظومة متكاملة للنسخ الاحتياطي والأمان (النسخ الفوري بضغطة زر، النسخ اليومي التلقائي مع مجدول المهام، استيراد وتصدير النسخ، وواجهة استعادة فائقة الأمان تأخذ لقطة أمان تلقائية قبل أي استعادة وتعيد تشغيل النظام بسلاسة).

## حالة التنفيذ

الوظائف المنفذة لا تشمل بعد صلاحيات الصفحات المخصصة لكل بائع، استلامات الموردين، المرتجعات، الجرد، تقارير المبيعات، تحصيل الآجل، الطباعة، توصيل الدرج، أو تليجرام. لا تُستخدم هذه النسخة لتشغيل محل فعلي حتى تكتمل تلك التدفقات وتُختبر.
